# Задача 29. Добавление брони

Уровень: лёгкий. Задача не зависит от других упражнений и не должна менять базу
после завершения.

## Что нужно сделать

Внутри транзакции создай одну строку в `bookings`:

- `property_id` — 7;
- `guest_id` — UUID любого существующего пользователя;
- заезд — `2025-10-01`;
- выезд — `2025-10-04`;
- гостей — 2;
- статус — `pending`;
- итоговая сумма — 27000.

ID и время создания должна заполнить база. Верни созданную строку через
`RETURNING`, затем выполни `ROLLBACK`.

## Ожидаемый результат

- `INSERT` возвращает 1 строку;
- число ночей равно 3;
- после `ROLLBACK` в `bookings` снова 511 строк.
