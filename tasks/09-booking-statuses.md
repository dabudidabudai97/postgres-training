# Задача 09. Статусы бронирований

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Выведи из `bookings` уникальные значения столбца `status`. Отсортируй их по
алфавиту.

## Ожидаемый результат

- 4 строки;
- каждый статус встречается только один раз;
- значения: `cancelled`, `completed`, `confirmed`, `pending`.

Подсказка: используй `DISTINCT`.
