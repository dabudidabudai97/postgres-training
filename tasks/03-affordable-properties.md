# Задача 03. Недорогое жильё

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Найди в `properties` активное жильё стоимостью не более 5000 рублей за ночь.
Выведи название и цену. Сначала должно идти самое дешёвое жильё.

## Ожидаемый результат

- 45 строк;
- цена каждой строки не больше 5000;
- строки отсортированы по цене по возрастанию.
