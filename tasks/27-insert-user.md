# Задача 27. Добавление пользователя

Уровень: лёгкий. Задача не зависит от других упражнений и не должна менять базу
после завершения.

## Что нужно сделать

Внутри транзакции добавь в `users` пользователя со своим именем и новым email.
Столбцы `uid` и `created_at` не передавай: база заполнит их автоматически.
Верни созданную строку с помощью `RETURNING`.

Заверши файл командой `ROLLBACK`, а не `COMMIT`.

## Ожидаемый результат

- `INSERT` возвращает 1 строку;
- UUID и время создания заполнены;
- после `ROLLBACK` пользователя с новым email в базе нет.

## Куда сохранить решение

`trainingPG/queries/27_insert_user.sql`

Файл должен самостоятельно содержать `BEGIN`, `INSERT` и `ROLLBACK`.
