# Задача 10. Количество ночей

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Для каждой строки `bookings` выведи ID брони и количество ночей между
`check_in` и `check_out`. Назови вычисляемый столбец `nights`.

## Ожидаемый результат

- 511 строк;
- все значения `nights` положительные;
- ID брони выводится явно.

## Куда сохранить решение

`trainingPG/queries/10_booking_nights.sql`

Подсказка: в PostgreSQL тип `date` можно вычитать из другого `date`.
