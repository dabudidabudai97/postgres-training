# Задача 20. Брони и гости

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Для каждого бронирования выведи ID брони, имя гостя, даты заезда и выезда,
статус. Связь: `bookings.guest_id = users.uid`.

## Ожидаемый результат

- 511 строк;
- каждая бронь встречается один раз;
- у каждой брони указано имя гостя.
