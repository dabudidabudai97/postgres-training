# Задача 28. Изменение цены

Уровень: лёгкий. Задача не зависит от других упражнений и не должна менять базу
после завершения.

## Что нужно сделать

Внутри транзакции:

1. Выведи текущую цену объекта с ID 7.
2. Увеличь её на 10%.
3. Верни ID и новую цену через `UPDATE ... RETURNING`.
4. Выполни `ROLLBACK`.

## Ожидаемый результат

- исходная цена — `9000.00`;
- новая цена внутри транзакции — `9900.00`;
- после `ROLLBACK` цена снова равна `9000.00`.
