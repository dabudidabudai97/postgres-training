# Задача 18. Жильё и города

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Для каждого объекта выведи его название и город. Свяжи `properties.city_id` с
`cities.id`. Назови столбцы результата `property_title` и `city_name`.

## Ожидаемый результат

- 127 строк;
- у каждого объекта указан город;
- один объект не должен появляться несколько раз.
