# Задача 23. Рейтинг жилья

Уровень: лёгкий плюс. Задача не зависит от других упражнений.

## Что нужно сделать

Для каждого активного объекта выведи название, среднюю оценку и число отзывов.
Отзывы связаны с жильём через бронирование:

- `properties.id = bookings.property_id`;
- `bookings.id = reviews.booking_id`.

Активное жильё без отзывов тоже должно попасть в результат.

## Ожидаемый результат

- 114 строк;
- у объекта без отзывов количество равно 0, а средняя оценка — `NULL`;
- один объект занимает одну строку.

## Куда сохранить решение

`trainingPG/queries/23_property_rating.sql`

Подсказка: используй `LEFT JOIN`, `AVG`, `COUNT` и `GROUP BY`.
