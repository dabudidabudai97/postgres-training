# Задача 07. Завершённые бронирования

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Из таблицы `bookings` выведи ID, дату заезда, дату выезда и итоговую сумму только
для броней со статусом `completed`. Сначала покажи брони с более поздним заездом.

## Ожидаемый результат

- 206 строк;
- в каждой строке статус исходной брони — `completed`;
- даты заезда отсортированы по убыванию.
