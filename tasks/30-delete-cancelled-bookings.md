# Задача 30. Удаление отменённых броней

Уровень: лёгкий. Задача не зависит от других упражнений и не должна менять базу
после завершения.

## Что нужно сделать

Внутри транзакции удали из `bookings` только строки со статусом `cancelled`.
Верни ID и статус удалённых строк с помощью `RETURNING`. После проверки выполни
`ROLLBACK`.

## Ожидаемый результат

- удаляются 102 строки;
- обе возвращённые строки имеют статус `cancelled`;
- после `ROLLBACK` в `bookings` снова 511 строк.

## Куда сохранить решение

`trainingPG/queries/30_delete_cancelled_bookings.sql`

Файл должен самостоятельно содержать `BEGIN`, `DELETE` и `ROLLBACK`.
