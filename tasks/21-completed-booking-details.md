# Задача 21. Подробности завершённых броней

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Выведи завершённые бронирования со следующими полями: ID брони, название жилья,
имя гостя, даты заезда и выезда, итоговая сумма.

Понадобятся связи:

- `bookings.property_id = properties.id`;
- `bookings.guest_id = users.uid`.

## Ожидаемый результат

- 206 строк;
- только брони со статусом `completed`;
- каждая бронь встречается один раз.
