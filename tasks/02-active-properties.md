# Задача 02. Активное жильё

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

Из таблицы `properties` выведи название и цену за ночь только для активных
объявлений. Признак активности хранится в `is_active`.

## Ожидаемый результат

- 114 строк;
- столбцы `title` и `price_per_night`;
- неактивное объявление в результат не попадает.

## Куда сохранить решение

`trainingPG/queries/02_active_properties.sql`

Не используй `SELECT *`.
