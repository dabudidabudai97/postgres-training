# Задача 17. Часто бронируемое жильё

Уровень: лёгкий. Задача не зависит от других упражнений.

## Что нужно сделать

По таблице `bookings` найди `property_id`, у которых есть минимум две брони не
со статусом `cancelled`. Выведи ID объекта и количество таких броней.

## Ожидаемый результат

- 124 строки;
- отменённые брони не учитываются;
- у каждой найденной строки счётчик не меньше 2.

## Куда сохранить решение

`trainingPG/queries/17_frequently_booked_properties.sql`

Подсказка: условие на исходные строки задаётся в `WHERE`, а на результат
группировки — в `HAVING`.
